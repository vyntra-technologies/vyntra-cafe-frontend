# ☕ Vyntra Cafe – Cafe Management System

**A Modern Digital Solution for Smart Cafe Operations.**

Vyntra Cafe is a modern, full-featured Cafe Management System designed to simplify and streamline daily cafe operations. It provides an elegant dashboard and centralized management tools for handling menus, orders, tables, reservations, inventory, and business analytics.

## ✨ Key Features

- **Dashboard:** Real-time business overview and performance insights.
- **Menu Management:** Manage food items, categories, pricing, and availability.
- **POS & Orders:** Efficient order processing and payment management.
- **Table Management:** Monitor table availability and dining status.
- **Reservations:** Manage customer bookings and reservations.
- **Inventory Management:** Track ingredients and stock levels.
- **Reports & Analytics:** Monitor sales, revenue, and business performance.
- **Settings:** Manage cafe configurations and system preferences.
- **Real-Time Updates:** Socket.IO-powered live operational updates.

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone YOUR_REPOSITORY_URL
cd vyntra-cafe
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the project root.

```env
VITE_API_URL=http://localhost:5000/api/v1
```

Update the API URL according to your backend configuration.

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```
